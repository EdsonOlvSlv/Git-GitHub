Sistema de Gestão de Bibliotecas

- Objetivo do Projeto:

O objetivo deste sistema é implementar uma aplicação de gestão de biblioteca utilizando Programação Orientada a Objetos em JavaScript, aplicando os principais conceitos vistos durante o módulo:

Abstração de entidades reais
Classes e objetos
Construtores, atributos e métodos
Encapsulamento com getters e setters
Herança e polimorfismo

A aplicação permite:

Cadastro, edição, exclusão e listagem de livros, autores e usuários
Registro de empréstimos e devoluções de livros
Histórico de empréstimos
Relatórios (livros mais emprestados e usuários que mais emprestaram)

- Como Rodar

Clone ou baixe este repositório.
Abra o projeto em um editor (VS Code recomendado).
Inicie o sistema abrindo o arquivo index.html em um navegador moderno (Chrome, Edge, Firefox).
O sistema não precisa de servidor ou dependências externas — funciona apenas com HTML, CSS e JavaScript puro.
